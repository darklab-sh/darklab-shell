## Highlights

- Project report groundwork is in place: owner-scoped report drafts, a shipped report template catalog, report preview routes, async markdown/HTML archive exports, redaction-aware report composition for selected project runs, targets, findings, triage, and artifacts, and a Projects modal Report tab for editing, saving, previewing, exporting, and using browser Print/PDF.
- Evidence package and report archive manifests now use v2 metadata with compact provenance blocks that record build settings, selected entity ids/counts, redaction/private-note choices, and safe source summaries. Package rows, package previews, manifest previews, and the Report tab show concise provenance summaries or compact source chips, while package manifests also record safe project-link provenance for selected runs and targets plus import hints and warnings for future archive review/recreation flows.
- Finding output in packages and reports now shows readable target references, including target type/value when export settings allow it, source run, relationship source, and redacted fallback matches when the finding text mentions a project target without a stored target id. Redacted outputs keep the relationship metadata and omit the target-reference value field.
