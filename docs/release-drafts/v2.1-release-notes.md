# darklab_shell v2.1 Release Notes

v2.1 turns command discovery into a single coherent surface — find a tool, see
what it does in this web shell, and learn its gotchas without leaving the
terminal — and tightens the terminal chrome so the tab strip gets room when you
need it.

For the full list of changes, see the v2.1 section in [CHANGELOG.md](../../CHANGELOG.md).

## Highlights

### Command knowledge layer

- **Per-command guidance in the terminal.** `commands info <tool>` now shows
  Notes, Gotchas, Safe Defaults, Common Flags, and Artifact Behavior alongside
  the existing description, examples, and flags — so you can pick the right
  command and avoid common web-shell surprises before you run it.
- **Search the catalog.** `commands search <term>` finds tools by name,
  category, description, example values, or guidance notes, grouped by category,
  with the most relevant (name-prefix) matches first.
- **Machine-readable details.** `commands info <tool> --json` prints the full
  catalog entry as one deterministic JSON line for copying or debugging.
- **App-native pipe helpers are discoverable.** `commands` now lists the
  built-in pipe helpers (`grep`, `head`, `tail`, `wc -l`, `sort`, `uniq`) with a
  clear note that they are app-managed filters, not arbitrary shell piping.
- **Output-aware `grep` autocomplete.** Inside a `| grep ` stage, autocomplete
  suggests tokens already visible in the active tab's output — IPs, hostnames,
  CVE IDs, HTTP status codes, and frequent words — so filtering recon output is
  a couple of keystrokes. Suggestions come only from the active tab and never
  widen what you're allowed to run.
- **Seeded guidance for twelve high-traffic tools** — `mtr`, `nmap`, `naabu`,
  `nuclei`, `gobuster`, `ffuf`, `testssl`, `dnsrecon`, `httpx`, `dnsx`,
  `subfinder`, and `katana` — focused on web-shell behavior: injected
  unprivileged scan types, status-line noise and the quiet flags that suppress
  it, and how output/input flags map into the session workspace.
- **Parity in the Command Registry modal** (Alt+C) — the same knowledge sections
  and pipe-helper list render in the browser surface as in the terminal.

### Terminal chrome polish

- **Auto-collapsing tab-bar chrome.** When the tab strip runs low on room, the
  right-hand controls (search, findings, summarize, line numbers, timestamps)
  collapse to a magnifier plus the findings badge so tabs reclaim the width. A
  `»`/`«` toggle expands them on demand or pins them open; the choice persists.
- **Tighter toolbar labels.** The line-number and timestamp toggles drop their
  `: on`/`: off` suffix (the indicator dot already shows state), and the search
  button no longer repeats the findings count shown in the badge beside it. The
  timestamp button still names its mode (`elapsed`/`clock`) when active.
- **Command outcome summaries.** Supported noisy tools (`nmap`, `dig`,
  `nslookup`, `curl`, and `openssl s_client`) can show a short deterministic
  outcome block below the raw transcript. Text, HTML, PDF, Run Details, and
  permalink/share exports show the same visible block without changing the raw
  transcript, and the feature can be toggled from Options or `config`.
- **Transcript noise groundwork.** Run output now has shared Python/browser
  metadata for deterministic progress, status, and boilerplate noise, with
  initial classifiers for high-chatter scanner lines from ffuf, masscan,
  ProjectDiscovery tools, and nuclei. New-run search text and command outcome
  summaries use the quieter view, run comparisons fold noise by default with a
  small note, raw transcripts stay unchanged, and signal-bearing lines still
  count as useful output. Evidence package transcript files stay raw, while the
  package manifest's transcript index uses the quieter view.
- **Shared tool-aware diffs.** Watcher diff classifiers now live in a shared
  `services.diff` package, leaving Watchers unchanged while letting run
  comparison expose nmap port/service and web URL/status changes with
  source-line jump pointers in a compact **Detected changes** section above the
  transcript diff.

### Fixes

- **History bulk-select drawer stability** — clicking **Select all** or
  **Clear** in History bulk mode no longer closes the drawer.
- **Atlas intel refresh feedback** — Refresh intel now shows a progress panel
  while slower provider lookups run, and duplicate refresh actions are disabled
  until the request finishes.
- **Dashboard readability** — the example Grafana dashboard's top-5 average
  run-duration panel now uses a wider horizontal bar view that stays capped to
  five tools across the selected dashboard range.

## Upgrade notes

- No migration or config change is required. The new `knowledge:` fields in
  `commands.yaml` are optional and descriptive-only — they never affect
  allow/deny policy, validation, or execution. `commands.local.yaml` overlays
  merge knowledge per the documented policy (scalar fields replace, list fields
  extend with dedupe). See
  [CONFIGURATION.md#command-knowledge](../../CONFIGURATION.md#command-knowledge).
