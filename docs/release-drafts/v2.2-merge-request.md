### Changed

### Fixed

- SQLite connections now set `wal_autocheckpoint=1000`, and Flask workers periodically run a guarded WAL truncate checkpoint so long-lived containers keep the SQLite WAL bounded.
- Redis-backed team active-run listings now use a `teamprocs:<team_id>` index instead of scanning every active-run metadata row for each team-scoped stream, event, or kill visibility check.
- Brokered command and interactive PTY streams now refresh active-run owner liveness immediately, then throttle repeated refreshes on busy streams to avoid per-frame Redis metadata writes.
- Startup now records run-output summary backfill status, so legacy runs with empty structured output or unreadable artifacts/previews are handled once instead of being retried on every restart.
- New full-output transcript artifacts now use hash-sharded `run-output/ab/abcd/<run_id>.txt.gz` paths, while existing flat artifact paths continue to load and delete from their stored metadata.
- History pages and run permalink JSON now reuse loaded label/note rows for label and note counts instead of running separate count queries for the same metadata.
- Static and vendor asset responses now use long-lived immutable browser caching while the main HTML route stays fresh.
- Shell, permalink, and diagnostics templates now render modular CSS through the asset manifest instead of walking the old `styles.css` import waterfall.
- Scanner-mode kill and API cancel requests now verify the stored PID start time before sending the sudo-backed process-group signal, so reused PIDs are treated as already gone instead of risking an unrelated scanner process group.
- The scheduler worker now runs daily retention pruning for expired runs, snapshots, run-output artifacts, and audit rows, so long-lived containers keep applying retention without a restart.
- Multi-worker startup now requires Redis; if `WEB_CONCURRENCY>1` and Redis is unavailable, the app fails fast instead of splitting active-run state across per-worker fallback maps.
- Dynamic app routes now have a baseline per-IP throttle before route matching, so broad HTTP scanners hitting random paths cannot crowd out normal browser, command start, or command kill requests. The default burst now gives the app's first page load enough room while the sustained per-minute cap still throttles unknown-path scans.
- Team-scoped audit rows now truncate long scope and target identifiers inside the audit table, keep the Details column visible at normal desktop widths, and expand details rows with a self-contained JSON envelope aligned back into the table.
- Project-scoped Findings Board refreshes now load each review column separately, so large New backlogs do not starve reviewed, false-positive, or follow-up columns.
- `scripts/check_versions.sh` now checks urlscan-cli against GitHub Releases, matching the calendar-versioned tags that install cleanly instead of stopping at the older Go module-proxy `v0.0.6` tag.
- `npm run assets:check` now owns the asset-builder cwd-independence check, and the Python docs guard skips that one check when Node dependencies are not installed.
- Projects and Files now close through the shared Escape/backdrop modal dismissal path again after the ESM migration, Shift+Option+F opens Files through an explicit Workspace import, and Option+Tab cycles tabs inside Options, Atlas, and Projects again.
- Mobile Projects controls now stop delegated click handling before async project hooks yield, so archived project expansion and artifact group collapse no longer toggle twice and appear unchanged.
- Sidebar workflow rows now use the same controller-owned Workflows opener as the rest of the app, preventing a scoped Workflows sheet from staying open and blocking the next source-mode lazy smoke action.
- Shodan autocomplete now follows the CLI's real scan shape: `shodan scan` suggests scan subcommands, and the target placeholder appears after `shodan scan submit`.
- Share snapshots created while a session token is active now post through the session-aware fetch boundary again, and rejected `/share` responses show the failure toast instead of copying a `...undefined` URL.
- Run Compare, History restore, and session-variable autocomplete now use the session-aware runtime fetch bridge in ESM runtime instead of relying on a legacy `window.apiFetch` mirror or raw `fetch()` fallback.

## Risks

- `/diag/audit` is operator-wide and IP-gated. Deployments should keep `diagnostics_allowed_cidrs` narrow because allowed callers can see personal and team audit activity.
- Browser Print/PDF depends on the user's browser print engine, so PDF output should still be spot-checked before sending reports externally.
- Provenance is intentionally bounded and redaction-aware. It explains selected evidence and safe source context, but it is not a full raw copy of every source payload.
