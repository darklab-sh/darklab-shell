# v2.2 Release Merge Request

## Summary

### Added

- Engagement report builder:
  - Adds owner-scoped report drafts, a shipped report template catalog with an operator override, report load/save/preview routes, async archive export jobs, download tickets, and report composition for selected runs, targets, findings, triage, and artifacts.
  - Adds the Projects modal Report tab for editing metadata, validating date ranges, choosing included evidence, saving drafts, previewing rendered HTML, exporting the markdown/HTML archive, and using browser Print/PDF.
  - Uses server-paged selectors for runs, targets, findings, and artifacts, keeps explicit None/All choices dynamic, stores filter-backed All selections with bounded exclusions, shows compact selected/excluded summaries, resolves manual selections beyond the visible page, and escapes Markdown table cells in the `.md` artifact.
- Richer package/export provenance:
  - Upgrades evidence package and report archive manifests to v2 metadata with compact provenance blocks for build settings, selected entity ids/counts, redaction/private-note choices, and safe source summaries.
  - Records report selection filters, bounded exclusions, and resolved build-time counts in report archive provenance so large filter-backed selections stay explainable after export.
  - Adds bounded project-link provenance for selected package runs and targets, plus import hints and warnings for package metadata, labels, notes, source links, target relationships, finding review state, redaction, private-note exclusion, and unavailable artifacts.
  - Shows concise provenance summaries or compact source chips in package rows, package previews, manifest previews, and the Report tab, with older/not-recorded fallbacks.
  - Includes readable package/report finding target references, source run, relationship source, stored confidence, and redaction-aware fallback matching; redacted outputs keep relationship metadata but omit target-reference values.
  - Adds safe audit correlation to job-backed package and report archive provenance without exposing session-derived details.
  - Adds safe selection counts, matched totals, selection modes, and exclusion counts to successful report export logs and audit rows.
  - Adds safe paging and filter-state context to report selector client-error logs without logging typed search text.
- Audit log surface:
  - Adds the `audit_events` table, config defaults, recorder/query helpers, startup and guarded periodic retention pruning, and a registry-backed event policy for fail-closed and best-effort audit rows.
  - Records bounded audit rows for history deletion, snapshots/redaction use, workspace file write/move/delete, project links, package/report builds, download tickets, Atlas entity suppression/deletion, Atlas import apply, finding review/suppression/deletion, secret lifecycle, session-token lifecycle/migration, team-management actions, automation definition changes, and notification-channel config changes.
  - Keeps sensitive values out of details: no raw tokens, one-time invite/recovery codes, file contents, imported row bodies, raw automation command text, webhook URLs, bot tokens, SMTP passwords, or replacement secret values.
  - Adds the IP-gated `/diag/audit` viewer with filters, target-aware event hints, safe detail drawers, available target/project links, and capped CSV/JSON downloads with truncation markers.
  - Adds a scoped Project Activity tab for personal project owners and team-scoped project viewers, with compact filters, offset paging, mobile rows, retention-aware empty states, and collapsed safe details.
  - Adds a scoped Team Activity subtab for owners/admins in Options → Teams, with safe governance/configuration rows, compact filters, offset paging, retention-aware empty states, and collapsed safe details.
  - Adds compact Recent activity panels to Project metadata edit sheets and the selected Team overview, with links back to the broader scoped Activity views.
  - Adds package/report build event type, job id, and correlation id handoff into job-backed archive provenance.

### Changed

### Fixed

- Startup now records run-output summary backfill status, so legacy runs with empty structured output or unreadable artifacts/previews are handled once instead of being retried on every restart.
- Dynamic app routes now have a baseline per-IP throttle before route matching, so broad HTTP scanners hitting random paths cannot crowd out normal browser, command start, or command kill requests.
- Team-scoped audit rows now truncate long scope and target identifiers inside the audit table, keep the Details column visible at normal desktop widths, and expand details rows with a self-contained JSON envelope aligned back into the table.
- Project-scoped Findings Board refreshes now load each review column separately, so large New backlogs do not starve reviewed, false-positive, or follow-up columns.

## Risks

- `/diag/audit` is operator-wide and IP-gated. Deployments should keep `diagnostics_allowed_cidrs` narrow because allowed callers can see personal and team audit activity.
- Browser Print/PDF depends on the user's browser print engine, so PDF output should still be spot-checked before sending reports externally.
- Provenance is intentionally bounded and redaction-aware. It explains selected evidence and safe source context, but it is not a full raw copy of every source payload.
