### Fixed

- Restoring a history run now reuses a tab only when the run identity matches, not merely when the command text matches.
- macOS double-space period substitution is normalized out of the command composer before it updates autocomplete or draft state.
- Terminal ANSI rendering now keeps parser state per tab and resets it before transcript replay, preventing unterminated colored output from leaking into another tab.
- Running tabs keep app-level shortcuts available from the prompt while command-entry and readline editing remain blocked; `Ctrl+C` still opens kill confirmation and `Ctrl+D` stays disabled until the run finishes.
- Project finding capture strips ANSI escape sequences before storing finding titles/raw lines, so colored scanner output is saved as plain text.
- Project auto-discovery no longer emits a fresh discovered-target notice when a run only rediscovers existing or dismissed targets.
- Project labels/notes editors stay hidden in the Projects modal empty state until a project exists.
- History row project actions now show **remove from project** for already linked runs instead of duplicate add actions, and link/unlink actions refresh the drawer immediately so menu state stays current.
- Recent-domain capture now skips file-list inputs such as `nuclei -l subs.txt`, while keeping target/domain/host suggestions available for those flags.
- Autocomplete now treats flags and value-taking triggers as case-sensitive, keeping both `dnsrecon -d` and `dnsrecon -D` visible while separating recent-domain suggestions from wordlist suggestions and avoiding output filename capture from a stale positional domain hint.
- The source-built OpenSSL command now loads its matching `/usr/local` libraries on arm64 and amd64 by installing them into the platform multiarch library path.
- App-native intel HTTPS lookups now verify provider certificates against explicit CA env settings or the system CA bundle, including container builds with source-built OpenSSL.
- Fast-exiting commands no longer show a false "Run not found" stream error while the server is still finalizing the completed run.
- `scripts/container_smoke_test.sh --build` now forces a rebuild of the stable smoke cache image before running the smoke corpus.
- Container smoke tests now use the Docker gateway when a GitLab Docker job reaches host-published ports through a mounted Unix Docker socket, and setup failures now fail the smoke job instead of skipping the entire command corpus.

## Risks

- **Project workspace scope is large for one release** — mitigated with route, unit, Playwright, doc-drift, package-export, and session-migration coverage plus focused review docs for remaining non-blocking gaps.
- **Evidence packages may expose private operator context if options drift** — mitigated by explicit private-note opt-in, redacted package modes, and regression coverage for manifest/archive note gating.
- **Interactive PTY mode has deployment-specific runtime requirements** — mitigated by default-off configuration, registry-owned command allowlisting, bounded concurrency, Redis/local broker paths, and startup/runtime guardrails.
