# v2.0 Release Merge Request

## Summary

- Adds Projects as the main v2.0 workspace surface, covering project CRUD, active-project shell context, terminal project commands, run links, targets, labels, notes, paged project data, server-backed filters, prefetched navigation counts, project-aware History flows, and desktop/mobile Projects modal workflows.
- Adds evidence packages for exporting selected project context, including transcripts, findings, targets, labels, notes, redacted variants, artifact controls, best-guess ZIP and expanded-size estimates, drift reporting, same-selection re-export, and Files-disabled transcript-only support.
- Adds Session Entity Atlas as a first-class triage surface for extracted entities and deduped findings, with project links, labels, notes, label/note-aware search, searchable source-run filters across Atlas tabs, run-retaining cleanup with curated-row guardrails, exports, saved views with one-click filter reset, reversible suppression, mobile support, large-session paging, and deferred intel payload rendering.
- Adds external intel integrations and the encrypted secrets vault, including provider status, app-native and CLI-backed lookups, normalized provider cache/rate-limit handling, safe secret storage, Options Secrets, and terminal `intel`, `providers`, `secret`, and `config` command support.
- Adds the scheduled-run foundation, watcher service composition, watcher diff classifiers, watcher browser routes, and browser/API/CLI schedule and watcher surfaces: durable schedule/audit tables, watcher state/fire-audit tables, strict cron and timezone helpers with a five-minute minimum custom interval, a service layer for normal and watcher-owned schedules, watcher fire/finalization hooks, structured finding/port/host/TLS/textual watcher diffs, missed-fire recovery, a supervised scheduler worker with deployment-wide locking and a documented `SCHEDULER_ENABLED` toggle, Postgres restart-tolerant scheduler polling, brokered due-run firing with revoked-token and overlap audit handling, structured scheduler lifecycle/rejection/recovery logs, explicit watcher diff-failure logging, full watcher lifecycle smoke coverage, the browser Schedules modal with completed-fire comparison actions, the browser Watchers modal with Run Details baseline handoff, first-run baseline capture, last-diff summaries, fire audit rows with readable changed counts, expandable details, and direct baseline-vs-fire comparison actions, keyboard shortcuts for both modals, scheduled badges in History/Run Details, `/schedules` CRUD/preview/fire-audit/run-now routes, `/watchers` CRUD/fire-audit/run-now/baseline routes, `/api/v1/schedules` and `/api/v1/watchers` readers/writers, expanded `darklab schedule info` inspection output, `darklab watch` management commands, and standalone schedule/watcher operator guides.
- Adds guarded interactive PTY mode for TTY-oriented tools, with tab-scoped xterm.js terminals, Redis-capable routing, concurrency limits, owner-displacement notices, stale-age reattach snapshots, completed transcript shaping, tunable runtime buffers, `/diag` operator metrics, and input/runtime safety controls.
- Improves command output, History, Run Details, and comparison workflows with high-volume live-render protection, canonical `/history/compare`, mobile-friendly saved-run actions, run-scoped Atlas counts/entities, bulk History actions, recent target autocomplete, and shared UI primitives for tabs, selects, pagers, output controls, and action sheets.
- Adds a typed run-output model foundation that separates transcript severity from visual role, keeps legacy `cls` compatibility, routes Python producers plus browser render/export consumers through the shared model, stores new full-output artifacts as headered JSONL, versions live SSE/NDJSON output with a schema frame, preserves SSE event names in NDJSON rows, indexes canonical entity values for History search, lets run comparison notice same-line kind/role changes, keeps registry-declared external help output out of findings and Atlas capture, falls back to preview output when a full-output artifact is missing, redacts matching entity canonical values for share/export paths, and locks the Python/browser schema with parity tests. History/API/CLI output reads now support structured selectors, Run Details and exports show structured summaries, completed runs can export txt/html/pdf from Run Details, permalink pages and saved HTML exports can toggle structured highlights, comparison/watchers/notifications/Status Monitor consume line metadata, and evidence package manifests include exported transcript line provenance.
- Adds a headless `/api/v1` surface and bundled `darklab` CLI for token-authenticated automation, non-interactive run start/active-list/tail/cancel, history/output/artifact reads, artifact download, read-only project reads, notification channel management, delivery audit reads, route-level OpenAPI schemas, SSE and NDJSON streams, and idle stream heartbeats.
- Adds larger-deployment support through Postgres backend selection, SQLite-to-Postgres migration tooling, body-store offload thresholds, `/diag` storage breakdowns, Prometheus `/metrics`, storage scaling guidance, and a disposable-container Postgres test helper.
- Improves operator logging with structured events for API runs, broker streams, PTY lifecycle, evidence package builds, migrations, secrets, Atlas cleanup/suppression, full-output fallback, and expected degraded states.
- Continues the front-end and backend module split so Projects, Atlas, Run Comparison, terminal composition, command registry, PTY, core helpers, and service code live in focused modules instead of broad shared files. `services.projects.workspace` remains as a compatibility export layer while new call sites use focused Project service modules directly, and Project routes share small JSON/404 helpers instead of repeating response boilerplate.
- Keeps the detailed Added/Changed/Fixed sections below as the historical work log for reviewers, while the release notes now group pre-release feature work into fewer user-facing themes.
