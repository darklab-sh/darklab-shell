# v2.0 Release Merge Request

## Summary

- Adds Projects as the main v2.0 workspace surface, covering project CRUD, active-project shell context, terminal project commands, run links, targets, labels, notes, paged project data, server-backed filters, prefetched navigation counts, project-aware History flows, and desktop/mobile Projects modal workflows.
- Adds evidence packages for exporting selected project context, including transcripts, findings, targets, labels, notes, redacted variants, artifact controls, best-guess ZIP and expanded-size estimates, drift reporting, same-selection re-export, and Files-disabled transcript-only support.
- Adds Session Entity Atlas as a first-class triage surface for extracted entities and deduped findings, with project links, labels, notes, label/note-aware search, searchable source-run filters across Atlas tabs, run-retaining cleanup with curated-row guardrails, exports, saved views with one-click filter reset, reversible suppression, mobile support, large-session paging, and deferred intel payload rendering.
- Adds external intel integrations and the encrypted secrets vault, including provider status, app-native and CLI-backed lookups, normalized provider cache/rate-limit handling, safe secret storage, Options Secrets, and terminal `intel`, `providers`, `secret`, and `config` command support.
- Adds guarded interactive PTY mode for TTY-oriented tools, with tab-scoped xterm.js terminals, Redis-capable routing, concurrency limits, owner-displacement notices, stale-age reattach snapshots, completed transcript shaping, tunable runtime buffers, `/diag` operator metrics, and input/runtime safety controls.
- Improves command output, History, Run Details, and comparison workflows with high-volume live-render protection, canonical `/history/compare`, mobile-friendly saved-run actions, run-scoped Atlas counts/entities, bulk History actions, recent target autocomplete, and shared UI primitives for tabs, selects, pagers, output controls, and action sheets.
- Adds a headless `/api/v1` surface and bundled `darklab` CLI for token-authenticated automation, non-interactive run start/tail/cancel, history/output/artifact reads, artifact download, read-only project reads, route-level OpenAPI schemas, SSE and NDJSON streams, and idle stream heartbeats.
- Adds larger-deployment support through Postgres backend selection, SQLite-to-Postgres migration tooling, body-store offload thresholds, `/diag` storage breakdowns, Prometheus `/metrics`, storage scaling guidance, and a disposable-container Postgres test helper.
- Improves operator logging with structured events for API runs, broker streams, PTY lifecycle, evidence package builds, migrations, secrets, Atlas cleanup/suppression, full-output fallback, and expected degraded states.
- Continues the front-end and backend module split so Projects, Atlas, Run Comparison, terminal composition, command registry, PTY, core helpers, and service code live in focused modules instead of broad shared files. `services.projects.workspace` remains as a compatibility export layer while new call sites use focused Project service modules directly, and Project routes share small JSON/404 helpers instead of repeating response boilerplate.
- Keeps the detailed Added/Changed/Fixed sections below as the historical work log for reviewers, while the release notes now group pre-release feature work into fewer user-facing themes.

### Fixed

- Project retention cleanup now removes stale project links for run-file artifacts owned by pruned runs, and session migration only moves `workspace_file` labels/notes when the source file actually moved to the destination workspace.
- Restoring a history run now reuses a tab only when the run identity matches, not merely when the command text matches.
- macOS double-space period substitution is normalized out of the command composer before it updates autocomplete or draft state.
- Terminal ANSI rendering now keeps parser state per tab and resets it before transcript replay, preventing unterminated colored output from leaking into another tab.
- Running tabs keep app-level shortcuts available from the prompt while command-entry and readline editing remain blocked; `Ctrl+C` still opens kill confirmation and `Ctrl+D` stays disabled until the run finishes.
- Project finding capture strips ANSI escape sequences before storing finding titles/raw lines, so colored scanner output is saved as plain text.
- Atlas entity extraction now captures URL hosts while ignoring file-like names inside URL paths, so CDN assets such as `all.min.css` and `awesome.svg` do not become domain entities.
  - Atlas cleanup now treats findings reached through project-linked runs or project-linked Atlas entities as curated by default, and cleanup confirmations have a separate opt-in for deleting curated single-source rows.
  - Run Details now opens Atlas scoped to that source run, Atlas can search/select a source run directly, and Atlas shows a clearable run filter chip while summary counts, entity tabs, exports, saved views, and the Findings queue use that run scope.
  - History run deletion, run-retaining Atlas cleanup, and project finding recapture now share Atlas aggregate recalculation so remaining findings keep accurate first/last source-run pointers.
  - Project finding payload normalization now returns the same core fields across stored finding rows, occurrence-backed rows, run-scoped rows, and review-update responses.
  - Mobile Atlas keeps saved-view Update/Delete actions disabled until a saved view is selected.
- Project services now share the existing text-trimming utility instead of keeping duplicate local helpers, and backend coverage compares core SQLite init schema with the Postgres migration registry for table columns, shared indexes, and Atlas finding triggers.
- Project auto-discovery no longer emits a fresh discovered-target notice when a run only rediscovers existing or dismissed targets.
- Project target auto-discovery now treats configured project target quota exhaustion as an expected skip, logging a warning without a server-error traceback.
- Project target quota accounting now ignores bulk-linked Atlas entities, while bulk/manual Atlas entity linking has a separate `max_project_entities_per_project` cap and still respects the overall project link cap.
- Manual Project targets entered as `host` now store IP literals as Atlas `ip` entities, matching auto-discovered command targets instead of creating domain-shaped IP rows.
- Postgres run finalization now wraps optional project, artifact, finding, and Atlas enrichment writes in savepoints, so recoverable finalize errors do not poison the transaction that stores the completed run.
- History search now checks offloaded run-search bodies when `runs_search_text_inline_max_bytes` stores a body-store pointer, keeping terms beyond the pointer preview findable on SQLite and Postgres.
- Project labels/notes editors stay hidden in the Projects modal empty state until a project exists.
- History row and Run Details project actions now show **remove from project** for already linked runs instead of duplicate add actions, including runs opened from Atlas when the Current Project card confirms the link. Link/unlink actions refresh the UI immediately so menu state stays current, and remove confirmations now separate disposable same-run Atlas entity links, curated entity links, and related finding impact before unlinking them from the project.
- Owner-view styled run permalinks now show Atlas entity and Atlas finding counts alongside the existing run metadata.
- Compose now passes `DATABASE_POSTGRES_JIT` through to the app container, `.env.example` shows the toggle, `CONFIGURATION.md` reflects current `app/conf/` reload and local-overlay behavior, and the named-schema migration example creates the schema before running app migrations.

- Host/IP command slots such as `ping`, traceroute-style tools, `nc`, `telnet`, `mtr`, `whois`, TLS scanners, `naabu`, and `rustscan` now offer recent IPs as well as recent domains without suggesting URL-only targets.
