# darklab_shell v2.0 Release Notes

For the full list of changes included in this release, see the v2.0 section in [CHANGELOG.md](../../CHANGELOG.md).

## Highlights

- Project workspace adds a case-style grouping layer for projects, runs, workspace files, artifacts, targets, findings, labels, notes, and packages:
  - Active project context now appears in shell chrome with a clickable HUD chip, automatic external saved-run linking, browser-owned administrative built-ins excluded from project run links, active-project external-run capture controls, transcript notices, cross-tab modal refresh, active-project preference migration, project-aware history filters, and History drawer project filtering.
  - Shell-first `project` commands include project create/use/archive/unarchive/delete flows, target management, backend quick-add inference, nested autocomplete, Link last run backfill, and linked-run/file link management. Backend APIs also support workflow promotion and run-label baseline comparison for follow-on UI surfaces.
  - The Projects modal adds current/archived grouping, project deletion, a focused target editor, project labels, autosaving entity-note-backed project notes, shared filters by target/run/finding status, finding sorting, run rows with per-run finding/artifact counts, run/finding/artifact/workspace-file/package label and note edit controls, artifact availability/checksum status, scoped artifact preview/download actions, clickable finding rows that restore and highlight source run lines, inline finding review controls, and package export navigation.
  - Targets and findings now support active-project target autocomplete, auto-discovered pending targets from typed command inputs and explicit target-list files with Confirm/Dismiss controls, persisted multi-target associations, run-scoped persisted finding capture/review with project-target matching, and retention warnings for expiring project-linked runs.
  - Evidence packages include preset/redaction/estimated-size summaries, download/re-package/delete/manifest-preview actions, a package wizard with explicit entity selection, run-grouped transcript/finding/artifact selection, selectable/collapsible run groups, pre-build size estimates, same-selection re-export, clearer drift messaging for missing selected entities, skipped-item reporting with pre-build unavailable-selection preview, and temp-file-backed download streaming.
  - Package archives include static `index.html`, `README.md`, selected permalink-context-backed run transcript pages, a versioned CSS/font snapshot for offline pages, full text companions for capped transcripts, finding and target JSON/Markdown exports with inline metadata, selected label/private-note metadata exports including package/workspace-file metadata, project/entity/target note Markdown exports, artifact size/hash drift checks, project notes in summaries, offline finding sorting, and redacted output for manifests, HTML, Markdown, finding exports, target exports, metadata exports, note exports, transcripts, transcript text companions, and filenames.
  - Backend support includes the database relationship model, project summary aggregation, run-scoped artifact/finding/label/note metadata in history, restored-run JSON, workspace file listings with labels/notes, permalink views, `/diag` object counts, capped draft evidence package archives, entity-scoped labels and notes, shared write-route limits, configurable project workspace quotas, async-safe app-native select option refresh for dynamic dropdowns, workflow-promotion API support, and baseline-label comparison API support.
- Interactive PTY mode adds a real terminal surface for screen-oriented tools such as `mtr --interactive`, `ffuf --interactive`, and `masscan --interactive`, backed by registry-owned settings, dedicated PTY routes, Redis-friendly control routing, and a single-worker local fallback.
- The live PTY surface uses a tab-scoped xterm.js modal with fit-addon support, startup asset preloading, asset-load retry handling, theme refresh, reusable tab overlays, hidden-tab resize suppression, desktop-only mobile guardrails, and the same close/kill confirmation flow used by normal running tabs.
- PTY runs support bounded concurrency per browser session, defaulting to four active PTYs, while keeping each live terminal scoped to the tab that started it.
- Reload recovery and Status Monitor Attach restore active PTY runs from bounded ANSI terminal snapshots, preserving colors, text attributes, cursor position, and the latest visible screen when server-side terminal capture is available. Redis-backed deployments publish distributed, rate-capped snapshots so any worker can serve reattach without sticky routing.
- Completed PTY runs preserve live terminal formatting in the modal while appending a saved static transcript and exit status to the parent tab. The command registry controls transcript shaping, so `mtr` saves the final visible frame while `ffuf` and `masscan` save scrolled findings without common transient progress/status redraw lines.
- Interactive PTY mode ships with safety guardrails: explicit `input_safety` profiles, native `Ctrl+C` forwarding, rate-limited input and resize requests, UTF-8 byte-aware input trimming, workspace-CWD-aware validation before spawn, a vetted command environment, clear server-side terminal capture dependency errors, stale state cleanup, and actionable snapshot failure statuses.
- SQLite run previews are now byte-bounded with `output_preview_max_mb`, preventing huge single-line scanner output from bloating the history database while preserving larger output in full-output artifacts when enabled.
- Startup history queries now use targeted SQLite indexes so large history databases do not delay the Recent and Workflows rail menus.
- History restore now distinguishes runs by run identity, so restoring a command no longer jumps to an unrelated existing tab with the same command text.
- The command composer now blocks macOS double-space period substitution from changing terminal input.
- Recent value capture now preserves complete IPv4 addresses entered in domain-style argument slots.
