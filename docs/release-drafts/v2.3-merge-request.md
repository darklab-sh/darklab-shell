# v2.3 Release Merge Request

## Summary

This release adds the external-tool integration set, Project digest notifications, and a Project Overview tab for v2.3. It stages the new binaries in the Docker image, exposes the supported command shapes through the registry, captures structured output into Command Findings and Atlas, adds app-native InternetDB/FOFA/ZoomEye providers, adds a safe app-native `jq` selector, preserves Nuclei template provenance across saved output, Run Details, packages, and imports, lets Projects send scheduled attack-surface digests through existing outbound notification channels, and gives each Project a target-focused summary of findings, certificate status, intel, ports, services, and recent changes.

## Added

- Pinned Docker image installs for `tlsx`, `cdncheck`, TruffleHog, `massdns`, and puredns.
- Command registry support for `tlsx`, `cdncheck`, TruffleHog, and puredns, including autocomplete, help smoke examples, workspace-aware file flags, runtime wrappers, and policy guardrails.
- Structured output capture for `tlsx -json`, `cdncheck -jsonl`, TruffleHog JSON, and puredns rows, with Atlas entities, findings, warnings, summaries, run-file artifact provenance, and redacted TruffleHog persistence.
- App-native Shodan InternetDB, FOFA, and ZoomEye intel providers, including provider readiness, secret suggestions, cache/rate-limit/quota handling, and terminal formatting.
- App-native `jq` pipe helper for safe JSON/JSONL field selection and simple filters across server-side and browser-side post-filter paths.
- Nuclei template-source provenance for live/saved output, Run Details restores, package transcript assembly, and Nuclei JSONL Atlas imports.
- A bounded Project Monitoring summary window contract for scheduled attack-surface digest notifications.
- Owner-scoped Project digest settings with cadence, explicit channel targets, quiet-digest behavior, and separate evaluated/sent timestamps.
- Hidden Project digest scheduler jobs that evaluate due windows, queue selected notification channels, and update sent-state after successful notification delivery.
- Compact Project digest notification payloads for webhook, chat, Pushover, and email-compatible channels, including safe top changes and Monitoring links.
- Project Monitoring digest controls for enabling scheduled digests, choosing cadence, selecting channels, showing schedule status, preserving read-only team viewer access, and surfacing digest project/window context in channel delivery history.
- Project Overview tab with bounded target rollups, certificate-health chips that keep unknown separate from healthy, finding severity chips, provider highlights, recent-change markers, and Entities/Findings deep-links that reuse the existing target filter params.

## Risks

- FOFA and ZoomEye availability depends on vendor account permissions and remaining credits, so configured providers may still return account-level quota errors.
- TruffleHog support intentionally avoids local Git paths, custom clone paths, and provider subcommands to keep scans inside managed boundaries.
- puredns support intentionally uses packaged wordlists and workspace-aware flags; positional session wordlists and `puredns resolve <file>` are outside the supported command surface.
- The app-native `jq` helper covers common JSON/JSONL selection only and is not a general jq runtime.
