# CVE risk data notices

darklab_shell includes dated bootstrap snapshots so a fresh or disconnected install can prioritize saved CVEs before live feed refresh is enabled.

- **FIRST EPSS:** Exploit Prediction Scoring System data is provided by FIRST. EPSS estimates the probability that a CVE will be exploited in the wild in the next 30 days. It isn't a complete risk score. See the [FIRST terms of use](https://www.first.org/about/policies/terms) and [EPSS documentation](https://www.first.org/epss/).
- **CISA KEV:** Known Exploited Vulnerabilities catalog data is provided by CISA. A catalog due date describes the BOD 22-01 requirement for U.S. Federal Civilian Executive Branch agencies; it isn't a remediation deadline set by darklab_shell. See the [CISA KEV catalog](https://www.cisa.gov/known-exploited-vulnerabilities-catalog).

These names and source notices identify the data used. They don't imply that FIRST or CISA endorses darklab_shell.
